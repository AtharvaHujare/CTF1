# The Hidden Parameter

**Category:** Web  
**Difficulty:** Moderate  

---

## Story

Nova Systems recently launched a new employee resource portal.

The development team claims that the old administration system was completely removed during the migration.

During a security audit, you are given access to the public portal.

Something about the new system doesn't feel completely clean.

Find what the developers forgot to remove.

---

## Setup & Running Locally

Ensure Python 3 is installed, then install the dependencies and start the web server:

```bash
pip install -r requirements.txt
python app.py
```

Access the challenge portal in your web browser at:

```text
http://127.0.0.1:5000
```
